AI-Forward · Reference Card 01

The Model Call

The one-page mental model. Everything downstream is a consequence of this.

Definition

One model call = send the entire context as one flat token string → get a sampled continuation back. Stateless. Text in, next token out, repeated.

Vocabulary

  • Token — the model's unit of text, ≈ ¾ of a word.
  • Context window — the finite token budget for one call. Holds system prompt + history + retrieved data + the reply. A shared resource you manage.
  • Stateless — no memory between calls; "memory" = your app resending the transcript.
  • Sampling — the reply is drawn from a probability distribution → nondeterminism; hallucination is a normal failure mode, not a malfunction.

The three consequences

  1. Stateless → resend everything every turn; memory & context management are your problem.
  2. One string → instructions and data aren't separated → prompt injection is architectural (OWASP LLM01).
  3. Sampled output → nondeterministic & can be confidently wrong → you need evals; never wire raw output to a privileged action.

Security spine

Every place untrusted text enters the context window is an attack surface. Direct = the user types it. Indirect = it rides in on content the model reads (web page, PDF, tool result). Delimiters/warnings ≠ a hard boundary. Defenses live around the model: least privilege, output validation, human approval in the loop.

Reflex to build

Given any AI feature, immediately ask: "What goes into the context string, and which parts of it are attacker-controlled?"
